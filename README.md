# 人类通关计划

[在线游玩](https://ziji1224054593.github.io/captcha-quest/)

独立的五关验证码小游戏，没有参数调整面板。

第一关只有一个拼块和一个缺口，拖动对齐后松手即可通过。通过后约一秒自动进入第二关。第二关延续原演示页的全部进阶效果，连续完成三轮匹配后自动进入第三关；失败可以重试本关，也可以从头开始。

## 本地运行

在此目录执行 `npm run dev`，访问 http://127.0.0.1:4174。无需安装依赖。执行 `npm test` 检查关卡推进与重开逻辑。

使用浏览器 ES 模块，请通过 HTTP 服务访问。静态部署需包含 index.html、所有运行时 JavaScript 和 CSS 文件，以及 vendor/captcha.js。

vendor/captcha.js 来自 morph-drag-captcha，增加仅供游戏第一关使用的 singleTarget 选项。原 npm 项目未修改。本项目用于娱乐，不作为业务安全校验；目前不支持只用键盘完成拼图。

## 第三关：反人类审查局

五轮连续匹配，反向双倍拖动、反向外环、远离目标时每 1.6 秒自转 45°、更快移动目标、1.2 秒连续对齐与 650ms 线索交替。进入目标附近后自转暂停，外环阶段继续冻结干扰，保留明确的可完成窗口。没有时间限制，失败重试本关。

## 过关计时

进入每关开始计时，失败和重试不清零，切换标签页仍计时。过关后冻结本关成绩，关间过渡不计入用时。通关展示每关及累计用时；从第一关开始或刷新页面会清零。

## 第四关：规则叛变

记忆目标、执行与反转指令、假通关提示和返回起点归档。通过第三关后自动进入；仅在开局说明规则，不提供操作指引。

## 第五关：行为拒绝实验室

通过第四关后自动进入。驱赶逃跑的目标进入收容区，再移动方块对齐。高速拖动有更大阻力，三轮依次反转 X、Y、双轴，最后需静止两秒后松手。红色倒计时无效。
